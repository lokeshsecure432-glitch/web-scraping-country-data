# Web Scraping Country Data Project

## Overview
This project extracts country-related data from a website using Python web scraping techniques.

The extracted data includes:
- Country Name
- Population
- Area

The data is cleaned and stored in CSV format using Pandas.

---

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas

---

## Project Workflow
1. Send request to website
2. Extract HTML content
3. Parse webpage using BeautifulSoup
4. Extract required country data
5. Store data in Pandas DataFrame
6. Export data into CSV file

---

## Files Included
- `web_scraping.ipynb` → Main Jupyter Notebook
- `country_data.csv` → Extracted dataset
